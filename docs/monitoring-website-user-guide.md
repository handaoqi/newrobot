# 监测网站使用指南

[返回文档中心](./project-docs-index.md)

## 1. 适用对象

本文面向监测网站的值班人员、演示人员和现场联调人员，说明如何登录网站、查看实时视频、处理风险事件、使用语音喊话和远程控制功能。

## 2. 访问与登录

### 2.1 访问地址

当前演示访问地址：

```text
http://39.106.208.174:13000/
```

如果后续启用 HTTPS 域名，应优先使用 HTTPS 地址，尤其是需要使用网页录音功能时。

### 2.2 登录账号

演示账号：

```text
用户名：operator
密码：admin123456
```

登录成功后会进入实时监测中心。浏览器会保存登录 Token，后续访问不需要重复登录。点击右上角退出登录可清除本地登录状态。

## 3. 页面导航

登录后左侧导航包含以下页面：

| 页面 | 用途 |
| --- | --- |
| 实时监测中心 | 查看实时视频、机器人状态、远程控制台、最近事件 |
| 统计分析中心 | 查看告警趋势、检测趋势和值守指标 |
| 事件中心 | 查询、筛选、复核和归档风险事件 |
| 机器人管理 | 查看机器人基础信息、状态、近期事件 |
| 巡检任务 | 查看巡检任务列表和执行状态 |

## 4. 实时监测中心

实时监测中心是日常值守主页面。

### 4.1 查看实时视频

进入页面后，左侧主区域会显示当前机器狗的视频画面。

正常状态下，画面来自：

```text
机器狗摄像头 -> 云端视频服务 -> 网站播放器
```

如果视频区域没有画面，可按以下顺序排查：

1. 确认机器狗板端程序正在运行。
2. 确认机器狗网络可访问云服务器。
3. 确认 ZLMediaKit 容器正在运行。
4. 刷新网页。
5. 查看是否有最近事件抓拍图作为回退画面。

### 4.2 查看机器人状态

页面会展示：

- 机器人编号。
- 当前区域。
- 在线状态。
- 电量。
- 网络强度。
- 当前任务。
- 今日告警数量。

如果设备列表中有多台机器人，点击某台机器人后，视频、控制台和历史事件会切换到该设备。

### 4.3 查看最近事件

右侧“历史事件识别”区域展示当前机器人最近识别到的事件，包括：

- 事件图片。
- 事件标题。
- 位置。
- 发生时间。
- 处理状态或复核结论。

需要处理更多历史事件时，进入“事件中心”。

## 5. 风险事件回溯与处理

### 5.1 进入事件中心

点击左侧导航“事件中心”。

事件中心用于查询和处理历史风险记录。

### 5.2 筛选事件

支持以下筛选方式：

| 筛选项 | 说明 |
| --- | --- |
| 状态筛选 | 全部、待处理、已处理 |
| 关键词搜索 | 可搜索标题、地点、机器人、事件类型、处置备注 |
| 时间范围 | 可选择开始时间和结束时间 |
| 排序 | 按检测时间排序 |

建议日常值守优先查看“待处理”事件。

### 5.3 查看事件详情

点击左侧事件列表中的某条记录，右侧会展示详情：

- 抓拍图或标注图。
- 事件位置。
- 机器人信息。
- 风险等级。
- 检测时间。
- 视频流 ID。
- 处置表单。

### 5.4 处置和归档

处理步骤：

1. 选择待处理事件。
2. 查看抓拍图确认现场情况。
3. 在处置备注中填写处理说明。
4. 选择复核结论，例如确认违规或误报。
5. 点击处理按钮提交。

提交后，该事件会变为已处理状态，后续可在“已处理”列表中回溯。

## 6. 语音喊话

实时监测中心右侧“远程控制台”提供语音喊话能力。

### 6.1 播放预置音频

操作步骤：

1. 在“音频”下拉框中选择音频。
2. 当前可选项包括“自行车驶离”和“注意避让”。
3. 点击“开始喊话”。
4. 系统会向机器狗下发播放命令。
5. 机器狗下载音频并通过外接 USB 音箱播放。

播放链路：

```text
网站选择音频 -> 后端创建播放命令 -> 机器狗轮询领取 -> 下载音频 -> USB 音箱播放
```

### 6.2 使用自定义音频 URL

如果需要播放其他已上传的音频，可在“自定义音频 URL”输入框填写可公网访问的音频地址，然后点击“开始喊话”。

注意：

- URL 必须是 `http://` 或 `https://` 开头。
- 机器狗必须能访问该 URL。
- 推荐使用 MP3、WAV、OGG、WEBM 等常见格式。

### 6.3 网页录音并播放到机器狗

操作步骤：

1. 点击“录音”。
2. 浏览器弹出麦克风权限提示时选择允许。
3. 对着电脑麦克风讲话。
4. 点击“停止”。
5. 可在网页上播放本地预览。
6. 点击“播放录音”。
7. 后端保存录音并创建播放命令。
8. 机器狗下载录音文件并通过 USB 音箱播放。

重要限制：

- 浏览器录音通常要求 HTTPS。
- 如果使用 `http://39.106.208.174:13000`，浏览器可能提示无法录音。
- 若出现“浏览器录音需要 HTTPS 访问”，需要切换到 HTTPS 域名访问。

## 7. 远程控制

实时监测中心的视频区域提供远程控制能力。

### 7.1 接管前确认

远程控制涉及机器狗运动，操作前请确认：

- 现场周围无人员或障碍物。
- 机器狗电量充足。
- 网络连接稳定。
- 操作人员能看到实时画面。
- 必要时有人在现场旁站。

### 7.2 进入远程接管

点击“接管”后，系统会下发 `takeover_enter` 命令。

接管成功后，页面会进入远程控制状态。此时可以使用方向控制和技能动作。

### 7.3 方向控制

支持：

- 前进。
- 后退。
- 左移。
- 右移。
- 左转。
- 右转。

长按方向按钮时，系统会持续下发运动命令；松开按钮后会下发停止命令。

### 7.4 技能动作

支持的动作以页面展示为准，当前包括：

- 站立。
- 趴下。
- 握手。
- 停止。
- 其他已接入 SDK 的动作。

### 7.5 紧急停止

如现场出现风险，立即点击“紧急停止”。

紧急停止会下发停止或被动状态命令，优先保证机器狗停止运动。

### 7.6 退出接管

操作结束后点击“退出接管”。

退出时系统会尽量：

1. 停止机器狗运动。
2. 释放 SDK 控制。
3. 回到手柄或非接管状态。

## 8. 机器人管理

该页面适合用于阶段汇报和运行态势查看。

## 10. 巡检任务

进入“巡检任务”页面可查看任务信息，包括：

- 任务名称。
- 巡检区域。
- 执行状态。
- 完成度。
- 时间安排。

当前任务数据主要用于演示和状态展示。

## 11. 常见问题

### 11.1 页面能打开，但视频无信号

处理建议：

1. 刷新页面。
2. 检查机器狗板端程序是否运行。
3. 检查机器狗是否正在向云端推流。
4. 检查云端 ZLMediaKit 是否运行。
5. 检查当前机器人 `play_urls.flv` 是否正确。

### 11.2 能播放预置音频，但录音按钮不可用

常见原因是浏览器安全策略限制。

处理建议：

- 使用 HTTPS 地址访问网站。
- 检查浏览器是否允许麦克风权限。
- 检查电脑麦克风是否可用。

### 11.3 点击播放录音后机器狗无声音

处理建议：

1. 检查机器狗外接音箱是否通电。
2. 检查音箱是否处于 USB 输入模式。
3. 检查音箱音量。
4. 检查机器狗是否识别 USB Audio 设备。
5. 检查机器狗日志中是否出现 `playing audio through USB ALSA device`。

### 11.4 控制命令失败

处理建议：

1. 确认已进入远程接管。
2. 检查机器狗 SDK 是否可用。
3. 检查板端控制服务是否启动。
4. 检查网络是否稳定。
5. 必要时先点击紧急停止，再退出接管。

### 11.5 事件图片加载失败

处理建议：

1. 刷新页面。
2. 确认 `/media/` 文件可访问。
3. 检查后端媒体文件是否存在。
4. 检查前端 nginx 是否代理 `/media/`。

## 12. 操作安全建议

- 远程控制前确认现场安全。
- 不要在人员密集区域测试高风险动作。
- 长时间无人值守时不要保持远程接管状态。
- 发现视频延迟明显增大时，不建议继续远程运动控制。
- 音频喊话内容应简短明确，避免频繁重复播放。
- 事件复核时应以抓拍图、现场视频和实际巡检情况综合判断。
