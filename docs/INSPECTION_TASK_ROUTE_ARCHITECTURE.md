# 巡检任务、地图与路径规划架构

更新时间：2026-08-24

## 1. 配置到执行

```text
地图管理 → 路径规划 → 巡检任务 → 巡检日历 / 立即执行 → 执行记录、轨迹和事件
```

地图提供底图、坐标原点、关键帧和活动版本；路线保存途经点、方向、NDT/RTK、避障和到点播报；任务模板绑定机器人与路线；日历负责自动执行时间。

对应前端路由为 `/dashboard/tasks/maps`、`/dashboard/tasks/routes`、`/dashboard/tasks/zones`、`/dashboard/tasks/calendar`、`/dashboard/task-executions/:executionId` 和 `/dashboard/tasks/tracks`。各页面通过统一 API service 读取和更新数据，地图、路线、禁区和轨迹之间使用地图 ID 与路线 ID 关联，不把真实运行数据写入源码。

## 2. 地图管理与建图完成边界

`MapsPage.vue` 同时支持上传地图、从机器人同步和现场建图。现场建图分为室内和室外两条状态机：

- 室内流程先完成传感器检查，再确认开始采集；走场结束后停止并保存地图。
- 室外流程在正式采集前增加 ENU 原点锁定和航向复核，确认航向稳定后才开始走场建图。
- 停止保存后，Edge Agent 继续完成退出建图、生成完整地图包和上传；前端只有在上传结果包含地图指标时才显示“本次建图结果”。
- 完成后的 ZIP 大小、机器狗目录大小、建图耗时等指标按机器人保存到浏览器 `localStorage`，刷新地图页可恢复；下一次成功启动/检查建图流程时清理上一轮结果。
- 地图包未完成上传时不能把中间状态误显示为最终结果；上传失败、状态轮询失败和取消建图都必须保留明确错误或反馈。

地图预览还可以显示建图轨迹和关键帧，查看地图文件清单、活动地图状态以及锁定原点提取出的全局 ENU。设置活动地图、清理地图、删除地图和下发机器狗地图切换都属于设备或数据副作用，必须经过确认并保留后端返回的错误信息。

## 3. 路径规划页面布局

- 步骤 1：选择地图。
- 步骤 2：填写路线信息。
- 步骤 3：维护途经点和方向、定位、避障、播报配置。
- 步骤 4：查看、加载、删除和预演已保存路线。
- 地图位于主工作区，占主要面积；演练时间轴与地图并列展示。
- 步骤 5：导航测试位于主卡片右下方，展示连接、定位、导航栈、初始定位、状态机和传感器操作。

步骤 1—4 可以独立展开或收起。收起只影响显示，不清理表单、途经点或导航状态。途经点删除使用明确的红色“删除”按钮。

地图工作区支持途经点添加、逐点方向编辑、地图缩放、建图轨迹/关键帧查看和机器狗位置查看；点击模式切换为位置检查时，先点击位置再点击朝向点，避免把未确认的航向直接用于导航。保存路线前必须选择地图并至少添加两个途经点。

导航测试区持续读取连接、活动地图、定位质量、导航栈和状态机。页面显示的机器人位置必须通过地图 ID 一致性检查；定位样本过期或地图不一致时隐藏不可信位置并给出原因。路线演练的时间轴、语音播报和动画在页面卸载时停止。

## 4. 机器人图示与安全约束

地图上的演练机器人、实时机器人和值守/执行详情机器人统一使用 `RobotDogIcon` 组件及 `robot-dog.svg` 资源。定位可信度仍通过外圈、标签和颜色表达，不改变位置计算、航向线或定位丢失标记。

路线保存、导航初始化、启动/停止导航、执行当前路线和急停仍然是设备副作用。前端布局重排不得修改 API 请求、按钮禁用条件、命令状态机、超时和清理逻辑。

### 4.1 移动设备工作台约束

所有任务相关路由复用 `DashboardLayout.vue` 的设备模式导航。桌面设备始终使用左侧竖向菜单；移动设备无论横屏或竖屏，都使用右上角圆形菜单按钮和右侧抽屉。各模式下任务页面保持地图、路线、表单和执行状态的语义顺序，页面主体允许纵向滚动；需要展示宽表格或地图操作区的局部滚动必须明确限制在对应组件内，不能把横向溢出扩散到整个页面。

本次平板视觉基线首批覆盖登录、监测中心、保安值守和远程控制，并增加 `2000×1200` 横屏大平板基线；任务地图/路线/禁区/轨迹页面继承工作台导航和全局宽度约束。后续扩展任务页面视觉回归时，必须沿用固定 fixture、横向溢出和触控尺寸检查，不得因为响应式重排改动地图坐标、路线 ID、任务状态机或设备命令 payload。

地图和路线页面在无后端、媒体或真实机器人环境时只允许执行静态布局检查、固定数据视觉检查和前端单元/构建验证；平板自动化 fixture 不调用保存地图、导航初始化、路线执行或急停接口。

手工验收至少覆盖：地图加载失败、无轨迹/无关键帧、建图上传中、建图失败与取消、室外原点/航向复核、地图与机器人不一致、定位数据过期、路线执行确认和急停按钮禁用状态。没有后端、媒体或真实机器人环境时，只执行静态检查和前端单元/构建验证，不向设备发送运动命令。
