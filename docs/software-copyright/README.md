## 3. 使用原则

1. 六项材料统一使用著作权人“北京知川科技有限公司”、产品定位“无界公园”和版本号“V1.0”。
2. 太阳宫公园只作为首个应用案例，不写入登记名称。
3. 方括号中的内容均为待补信息，提交前必须替换或删除。
4. 说明书只能使用已经实现、能够运行并可由代码或截图证明的功能。
5. ROS2、Nav2、机器人厂商SDK、第三方AI模型和媒体服务单独列为依赖，不作为自研核心代码。
6. 本材料包是技术材料初稿，不替代登记机构或知识产权专业人员的最终形式审查。

“无界公园”在本材料中指边界开放、出入口多、人车活动动态、需要连续感知和机动巡检的城市公园及相似公共空间，不指单一地理项目或公司品牌。

## 4. 当前审计结论

现有仓库能够为实时监测、事件管理、地图管理、路线规划、任务执行、远程接管、语音喊话和轨迹回放提供代码证据。自动回充、完整自动巡检报告以及所有硬件状态字段的真机稳定性仍需在申报前确认，因此未作为六项V1.0的必备功能。
