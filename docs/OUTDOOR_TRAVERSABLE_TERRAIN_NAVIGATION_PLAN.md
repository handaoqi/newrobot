# 室外可跨越地形导航实施计划

## 目标

四足在所有导航路段自动通过连续、可支撑的 5–50 cm 台阶或平台；大于 50 cm、未知地形和无法确认支撑面的物体仍为障碍。现有二维 LaserScan/PGM 不保留高度，不能只靠提高高度阈值完成该策略。

## 已确认的实施边界

- 自动攀越：接近合格地形时仅允许低速前进；成功登顶后继续导航。
- 登顶依据：激光与 IMU 的连续地形证据；证据缺失、传感器陈旧或姿态异常立即停车。
- 所有导航路段启用；不按路线手工标记。
- 阈值：相对局部支撑面 0.05–0.50 m。基础建图和二维扫描先调整为 0.50 m，避免把低草、地面和已跨越台阶投影为普通障碍。

## 实施顺序

1. 统一建图、地图重建和导航 LaserScan 的最低高度为 0.50 m，并保持 `min_points_per_cell=3`、`support_radius_cells=1`；修复离线回环/救援重建遗漏这两个稠密度参数的问题。
2. 新增三维地形过滤与状态机，输出不可跨越点云、可跨越状态和原因；局部代价地图、Collision Monitor 与调试包消费同一过滤结果。
3. 地图保存生成原始 PGM 之外的可跨越派生导航图；路径/航点足迹预检和路径平滑均验证该图，原始路径不安全时不再回退放行。
4. 在受控场地用 5、25、50、51 cm 台阶及箱体、墙体、人员进行回放和低速验收；任何无法确认的情况进入零速安全暂停。

## 当前地图的限制

2026-09-13 室外路线 1 号点中心虽然是自由格，但最终足迹内有原始静态致命格；局部代价地图为空。该点的 PCD 高度约 0.20–0.71 m，重新按 0.50 m 投影后仍须做足迹预检；不得承诺会自动放行。
