# 保安值守：到点收敛与循环继续方案

已执行的实施基线：

- 到点 XY 微调使用碰撞监控后的 `cmd_vel_raw` 通道，保持定位新鲜度、扫描方向净空、平滑校正和机器人停车门控。
- 微调默认预算为总位移 `0.90 m`、每段 `0.15 m`、最多 `6` 段、总时限 `45 s`；控制目标进入业务 XY 容差内 `2 cm`。旧的 `0.45 m` 初始误差值只保留为诊断信息，不再阻止 `0.675 m` 等可在总预算内收敛的残差。
- 每段结束必须重新取得连续 `3` 帧新鲜定位。未达标时可继续下一段；预算、超时、扫描或定位安全门控失败时保持停车并进入自愈，不继续发布速度。
- 当循环上一轮末点与新一轮首点重合时，先按该首点的 XY/朝向策略取得连续新鲜确认。成功后持久化当前索引并记录 `task.loop_anchor_confirmed` 审计事件，直接下发下一个点；不会重复产生 `waypoint_reached`、播报、动作或 dwell。确认失败则正常下发该首点。
- 保安值守的“结束任务”主操作在人工暂停、等待安全条件或定位恢复观察时切换为“继续”；继续创建新的恢复 episode，先完成 5 秒安全观察，再下发 `task.recover.v1` 从 Edge 持久化的航点/阶段恢复。自愈次数耗尽时保留暂停上下文等待该操作，不强制取消任务。
- 人工接管时继续按钮保留但禁用并提示“先退出人工接管”；急停、低电量、越界和未停车等安全联锁同样不能被继续操作绕过。恢复请求进行中显示“自愈中”，防止重复提交。

本文件记录产品决策和验收边界；部署、真实机器人运动与发布由单独的变更授权执行。
