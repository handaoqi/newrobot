# FAST-LIO 航向保护与低电自动回充修复计划

## 目标

- 为 `/odom/lio_odom` 增加单帧航向变化和派生角速度门限；异常时拒绝该帧、保持最后可信位姿、立即停车并主动重定位。
- 将终态任务取消改为幂等，消除低电处理在任务恰好失败时进入慢速 `force_exit` 的约 66 秒等待。
- 充电服务启动后立即刷新桩端状态；等待接触时持续监测，蓝牙和极片条件满足后自动且仅启动一次充电。
- 修正回充任务先校验旧地图、后切换充电地图的顺序，避免 `MAP_VERSION_MISMATCH`。

## 实施决策

1. FAST-LIO 连续主源门限采用 `12 deg/frame` 和 `60 deg/s`。当前 Nav2 最大角速度为 `0.35 rad/s`（约 `20 deg/s`），因此默认门限保留三倍动态余量。
2. 航向异常按上升沿锁存。异常期间禁止 FAST-LIO 自动重锚和里程计桥接，定位输出保持最后可信位姿并报告 `status=4`；NDT/VGICP 只用于诊断和重定位验证。
3. `/localization/decision` 上报异常原因、实测值和门限；Edge Agent 对该事件绕过普通五帧定位丢失防抖，立即停止导航并从最后可信位姿重定位。
4. 终态取消保留原来的 `completed/failed/cancelled/timed_out/rejected` 结果，不再访问 Nav2 取消服务；重复调用返回 `already_terminal=true`。
5. 充电服务启动后同步执行一次 power-only 刷新。未接触时以 1 Hz、最长 300 秒继续刷新；接触满足后由幂等锁保证只执行一次 `_begin_charge()`。
6. VGICP 继续作为初始化、恢复或 NDT 质量不足时的条件式精化器，不改为每帧必跑。

## 验收标准

- 航向异常后一个定位周期内输出 `status=4` 和零速度，1 秒内进入主动重定位；异常姿态不得成为新的 FAST-LIO 地图锚点。
- 正常 `0.35 rad/s` 转向不误触发；跨 `+pi/-pi` 的正常航向连续变化计算正确。
- 低电处理遇到已经终态的任务时 1 秒内完成，不调用 Nav2 cancel 或 `force_exit`，并立即发布回充请求。
- `charge.start` 的首次响应使用服务启动后的桩端状态，不再错误显示“旧版充电诊断未运行”；极片接触后只开始一次充电。
- 跨地图 docking 任务在充电地图切换并定位稳定后通过校验；普通任务地图不一致仍然拒绝。

## 安全约束

- 自动化测试不触发真实运动或充电。
- 真机停车、导航、对桩和充电验收必须获得明确授权，并由现场人员确认路径及桩位安全。
