# 到点 XY 自愈与保持航向微调

## 已确认策略

- 首次 XY 稳定验收失败时，禁止 `cmd_vel` 补偿；只允许“静止校正 → 重新验收 → Nav2 重接近”。
- 最终 yaw 已完成后，只要 XY 残差超过普通0.30 m验收半径即可尝试受限 `cmd_vel` 微调，不再设置按初始残差计算的启动上限。
- 微调的 XY 是唯一位置目标；目标 yaw 始终是原航点 yaw。检测到偏差时只用限幅角速度回拉该目标，绝不将 yaw 改为行进方向。
- 微调或一次Nav2细靠近后仍超过0.50 m时禁止继续移动；连续安全观察5秒后先执行精准静止定位恢复，再对原航点粗靠近一次。
- `1.50 m` 仅保留为未经定位恢复时禁止直接重靠近的兼容安全参考，不是恢复成功后的导航禁令：绝对定位重新稳定后，Nav2 可以校正后的当前位姿为起点规划，即使两者距离仍大于 `1.50 m`。
- 普通/precision/dock 的最终 XY 门限分别为 `0.30 / 0.15 / 0.08 m`；普通稳定验收 3 帧，precision 与 dock 为 5 帧。
- 微调每段最多 `0.30 m`、累计最多 `0.60 m`、最多 2 段、总时限 30 秒；每段归零后重新校正与验收。普通点回到0.50 m粗圈即可降级完成。

## 到点状态机

`停车确认 → 定位校正 → XY 稳定验收 → xy_verified → 并行播报/非运动动作/dwell/yaw → 保持 yaw 微调 XY → 最终复核 → postprocess_completed → 下一航点`

失败不会发布 `xy_verified` 或启动副作用。微调及最终 yaw 失败不会降级跳过航向；按残差进入 Nav2 重接近或精准定位恢复。急停、低电量、边界、碰撞、扫描过期和人工独占接管始终优先触发安全停车。
