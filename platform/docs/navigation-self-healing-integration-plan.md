# 导航模块完善与现行 5 秒循环自愈兼容计划

## 对比结论

现行方案不是“每 5 秒执行一次恢复动作”，而是中心监督器每秒检查一次，确认机器人连续安全静止 5 秒后，才下发一次 `task.recover.v1`。

| 处理项 | 现行 5 秒方案 | 原规划 | 兼容后的设计 |
|---|---|---|---|
| 循环调度 | 中心持久化状态机负责 | 未明确纳入 | 保持中心为唯一循环调度者 |
| 恢复前门禁 | 连续安全观察 5 秒 | 侧重 Edge 预算 | 原样保留 |
| 恢复次数 | 每个异常最多 10 次 | 最多 6 次 | 中心、Edge 上限统一为 10 |
| 耗尽处理 | 强退当前轮，休息后继续下一轮 | 整场进入安全保持 | 按现行方案结束本轮并继续，但必须先确认停车 |
| 定位恢复 | Edge 异步执行，命令先返回 paused | 统一 180 秒恢复 | 保留异步机制，恢复进行中不重复消耗尝试次数 |
| BT 恢复 | 与 Edge 独立运行 | 引入共享仲裁 | 仲裁作为 5 秒方案的下层执行保护，不替代中心状态机 |
| 路径平滑 | 未实际启用 | 选择性启用 | 独立落地，不改变循环状态语义 |
| 碰撞保护 | 已运行，后退/旋转存在绕过 | 方向化保护 | 作为所有恢复动作的最终硬门禁 |

保存本计划时，现行分支基线测试已通过：中心侧 61 项、Edge 侧 128 项，共 189 项。

## 兼容性修正

现行实现需要在扩展导航模块前修正以下衔接问题：

- 定位恢复返回 `localization_recovery_in_progress` 时，中心保持 `recovering`，等待 Edge 完成或失败事件，不重新下发命令，也不增加 `recovery_attempt`。
- 恢复成功后清空 `recovery_episode_id`、原因和次数。否则下一次发生相同原因时可能命中旧的 `episode + attempt` 幂等命令。
- 将“异常根因”和“5 秒观察被重置的安全阻塞原因”分开保存，避免 `ROBOT_NOT_STOPPED` 等观察条件覆盖真正的定位或导航故障。
- 恢复达到 10 次时，先下发 `task.force_exit` 并确认执行终态、机器人停车；确认后进入轮间休息，再开始下一轮。停车无法确认时终止循环并报警。
- Edge 恢复预算改为按 `recovery_episode_id` 管理并随任务上下文持久化，Edge 重启不能重置同一异常的预算。
- 保留 `task.recover.v1` 和现有循环 API；新增结果字段均为可选，旧 Edge 返回缺少新字段时继续按 `final_task_state` 兼容处理。

`task.recover.v1` 增加可选结果：

- `recovery_status`：`recovered`、`in_progress`、`retryable_failure`、`non_retryable`、`already_running`。
- `recovery_action`、`retry_after_seconds`、`recovery_episode_id`、`attempt`。
- 当前恢复所有者、动作预算、累计时间和位移。
- Edge 异步恢复结束后发布幂等的 `task.recovery_completed` 或 `task.recovery_failed`。

## 恢复状态流程

1. Edge 或 BT 无法继续导航，停止运动并上报 `task.safe_hold`。
2. 中心循环进入 `observing`，每秒检查：
   - Edge 在线且遥测不超过 15 秒。
   - 无急停、无人工接管。
   - 电量不低于 20%。
   - 速度不超过 0.05 m/s。
3. 任一条件中断便重新计算连续 5 秒窗口。
4. 观察通过后下发当前异常的第 `N/10` 次 `task.recover.v1`。
5. 根据结果处理：
   - `recovered/already_running`：清除异常 episode，回到 `running`。
   - `in_progress`：保持 `recovering`，不增加尝试次数，等待异步结果。
   - `retryable_failure`：返回 `observing`，重新进行连续 5 秒观察。
   - `non_retryable` 或第 10 次失败：确认强退当前轮，休息后继续下一轮。
   - 低电量：立即终止整个循环，不观察、不重试。
   - 人工暂停、急停、人工接管：不允许自动恢复。
6. 循环截止时间包含观察、恢复和休息时间；截止后结束当前执行并确认停车。

普通终态执行仍按现有逻辑进入轮间休息。到点偏航降级继续仅允许普通 `stop_and_confirm` 航点、定位可信、距目标不超过 0.60 m；精准点和停靠点禁止降级。

## 模块落地

### 路径平滑

- 启动并纳入生命周期管理标准 `smoother_server`。
- 配置 `SimpleSmoother` 和 `PassthroughSmoother`：
  - 室内普通航段使用平滑。
  - 室外 RTK 直线、停靠、精准末端和短路径旁路。
- BT 先生成原始路径，再尝试平滑；平滑超时、碰撞或校验失败时自动使用原始路径，不触发循环自愈。
- 平滑限制：250 ms、端点偏差不超过 0.05 m、横向偏差不超过 0.30 m、长度变化不超过 ±10%。

### BT Navigator 与 Behavior Server

- BT 负责动作内部的快速局部恢复：重新规划、清理代价地图、等待和安全转向。
- 默认 BT 移除主动重定位和 BackUp，避免与 Edge 重复执行。
- Spin 每次默认 45°，必须取得 Edge 提供的恢复租约，并通过 Behavior Server 的代价地图碰撞预测。
- Edge 继续负责定位恢复、导航栈恢复、后向净空检查后的后退、当前航点重发。
- 两棵默认导航树保持相同的平滑、回退和恢复结构。

### 恢复仲裁

- 新增 `/navigation/recovery/lease`，由 Edge 当前任务上下文提供。
- BT、定位恢复、障碍恢复、到点微调和导航栈恢复共用单一运动所有者。
- 租约 TTL 为 3 秒，每秒续租；取消、超时、低电量、人工接管或进程异常时释放并停车。
- 每个异常中心尝试上限和 Edge 动作尝试上限均为 10，但分别记录，避免一次长时间定位恢复被误算成多次物理动作。
- 任一 Edge 硬预算耗尽即返回 `non_retryable`，中心不再浪费剩余命令次数。
- 独立硬安全预算：
  - 单异常最长恢复 180 秒。
  - 恢复累计平移不超过 1.2 m。
  - 障碍 episode 最多后退一次、距离 0.30 m。
  - 累计恢复转向不超过 180°。
  - 定位恢复最多 3 个周期且不超过 180 秒。
  - 导航栈每个 episode 最多重启一次。

### Collision Monitor

- 保持在最终速度出口，所有导航及恢复速度必须经过 `cmd_vel_nav → velocity optimizer → collision monitor → cmd_vel`。
- 前向、后向和旋转分别使用对应保护区域，不再无条件放行后退或原地转向。
- 激光数据超过 0.5 秒、定位超过 0.75 秒未更新时，只要存在非零输入速度便输出零速度。
- 状态遥测增加触发原因、多边形、数据源延迟、输入/输出速度和恢复租约所有者。
- Collision Monitor 的停车不等待中心 5 秒逻辑；它始终作为实时硬安全层执行。

## 值守界面

- 保留现有循环状态、轮次、休息时间和 `N/10` 自愈展示。
- 明确区分：
  - “连续安全观察 3/5 秒”。
  - “第 N/10 次恢复命令”。
  - “定位恢复进行中”。
  - “BT 局部恢复/Edge 恢复动作”。
  - “正在确认本轮停车”。
- 展示规划、平滑、控制、碰撞保护的模块链路以及原始/平滑路径。
- 展示异常根因、当前观察阻塞原因、恢复所有者、动作预算和恢复时间线。
- 地图切换、初始化定位、主动重定位和导航栈恢复时，同步刷新路径规划中的定位尝试区域。
- 恢复耗尽后显示“本轮已结束，等待健康门禁后继续下一轮”，避免误显示为整场循环停止。

## 测试与上线

- 为现有 189 项基线测试增加：
  - 连续 5 秒被速度、急停、人工接管或遥测过期打断。
  - 定位 `in_progress` 不递增尝试、不重复启动恢复线程。
  - 恢复成功后相同原因产生新的 episode。
  - 第 10 次失败先确认停车，再休息并创建下一轮。
  - Edge 重启后恢复次数和预算不清零。
  - BT 与 Edge 同时申请恢复时只有一个获得租约。
  - Collision Monitor 阻止不安全的转向和后退。
  - 平滑失败仅回退原始路径，不误触发循环恢复。
- 第一阶段上线协议字段、状态机修正、遥测和仲裁，路径平滑默认旁路。
- 第二阶段在仿真和静止故障注入中验证 5 秒状态流、定位异步恢复和 10 次耗尽流程。
- 第三阶段经明确现场授权后低速验证室内导航、障碍后退、定位丢失、导航栈重启和循环续轮。
- 第四阶段仅为室内普通航段灰度开启路径平滑；RTK 直线及精准停靠继续旁路。
- 回退时可关闭路径平滑和 BT 运动恢复，但不得关闭 Collision Monitor、低电量强退或现行中心 5 秒安全观察。
