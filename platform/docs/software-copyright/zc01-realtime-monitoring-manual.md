# 无界公园机器人实时视频与设备状态监测软件V1.0使用说明书

著作权人：北京知川科技有限公司  
版本：V1.0  
文档状态：初稿

## 1. 软件概述

本软件面向边界开放、出入口多、人员活动动态的无界公园及相似公共空间，为值守人员提供统一的实时视频与设备状态监测入口。软件通过中心平台接收机器人主动上报的视频引用、心跳和遥测信息，集中展示机器人当前位置、在线状态、电量、网络、定位状态和当前巡检任务。

太阳宫公园是本软件的首个示范应用。值守人员可在保安室浏览器或Pad端选择机器人，查看现场视频和设备运行状态，及时发现离线、定位异常或电量不足等情况。

## 2. 主要功能

1. 用户登录和访问控制。
2. 多机器人列表与当前设备切换。
3. 实时视频播放和无视频提示。
4. 在线状态、最后心跳和连接状态展示。
5. 电量、网络、定位、温度等遥测展示；无真实数据时显示不可用。
6. 当前区域、地图、任务和任务进度展示。
7. 最近事件概览及监测统计入口。

## 3. 运行环境

中心端采用Web前端与业务后端部署方式，值守终端通过浏览器访问。具体服务器、数据库、浏览器和机器人端版本以[申报信息采集表](./00-information-collection.md)定稿数据为准。

## 4. 操作流程

### 4.1 登录系统

用户输入授权账号和密码。认证成功后进入实时监测中心；认证失败时系统提示重新输入，不保存明文密码。

截图占位：`[ZC01-01 登录页面]`

### 4.2 选择机器人

在设备区域选择目标机器人。切换后，视频、状态、当前任务和最近事件同步更新为所选设备的数据。

截图占位：`[ZC01-02 机器人选择]`

### 4.3 查看实时视频

视频区域显示机器人摄像头画面。视频不可用时，页面给出断流或等待提示，并允许使用最近事件抓拍作为辅助信息，不用虚假画面替代实时视频。

截图占位：`[ZC01-03 实时视频]`

### 4.4 查看设备状态

状态区展示机器人编号、当前区域、在线状态、电量、网络、定位、温度和当前任务。无法获得的硬件指标明确显示“未知”或“不可用”。

截图占位：`[ZC01-04 设备状态卡]`

### 4.5 查看异常提示

设备离线、定位丢失、低电或任务异常时，页面使用状态颜色和文字提示值守人员进一步检查。

截图占位：`[ZC01-05 异常状态提示]`

## 5. 异常处理

- 视频无画面：检查机器人网络、视频服务和播放地址。
- 设备离线：检查最后心跳、边缘代理和消息连接。
- 指标不可用：确认对应传感器或ROS消息是否真实发布，不填写固定正常值。
- 页面数据未更新：刷新页面并检查中心服务状态。

## 6. 技术特点

软件采用中心平台与机器人边缘代理分离的架构，由机器人主动连接中心平台，适应移动网络NAT环境；状态数据包含采集时间和设备标识，便于区分多设备并避免旧状态覆盖新状态。
