# 六项申请表功能简介初稿

以下文字可作为申请信息表“主要功能和技术特点”的底稿。正式提交前须根据最终软件版本、登记系统字段长度和实际完成状态压缩或调整。

## ZC-01 无界公园机器人实时视频与设备状态监测软件V1.0

本软件由北京知川科技有限公司面向边界开放、出入口多、人员活动动态的无界公园及相似公共空间自主开发，用于对移动巡检机器人的现场视频和运行状态进行集中监测。软件通过中心平台接收机器人主动上报的心跳、定位、任务和设备遥测信息，并在浏览器端统一展示机器人编号、在线状态、当前位置、当前地图、巡检任务、电量、网络、定位和温度等指标；当某项硬件数据不可获得时，系统明确显示未知或不可用，避免以固定数据代替真实状态。值守人员可在多台机器人之间切换，联动查看实时视频、设备状态和最近事件。软件采用中心平台与机器人边缘代理分离的架构，机器人通过移动网络主动建立安全连接，适应NAT和弱网环境；状态信息包含设备标识、采集时间和状态版本，便于实现多设备隔离及新旧状态保护。太阳宫公园作为本软件首个示范应用，用于支持保安室对巡检机器人的日常值守和异常发现。

## ZC-02 无界公园安全事件智能识别与预警处置软件V1.0

本软件由北京知川科技有限公司面向无界公园开放空间的安全管理场景自主开发，用于接收机器人端或中心智能识别服务产生的安全事件，并完成规则判断、预警生成、人工复核、处置归档和统计分析。软件可记录事件类型、风险等级、机器人、发生时间、地图位置、关联任务、抓拍图片及视频引用，并通过事件标识和去重规则降低重复告警。管理员可在指定地图版本上配置电子围栏或禁行区域，值守人员可按状态、时间和关键词查询事件，查看识别画面和上下文，提交确认违规、误报等复核结论及处置备注。软件将模型检测结果与最终业务结论分离，保留原始检测信息和人工处理记录，支持事件全过程追溯。太阳宫公园V1.0重点应用为自行车进入禁行区域的识别和劝导，系统同时保留人员、车辆、垃圾和动物等事件类型的扩展接口。

## ZC-03 无界公园机器人地图构建与路线规划软件V1.0

本软件由北京知川科技有限公司面向无界公园的移动机器人自主巡检场景开发，用于完成现场建图组织、地图文件同步、地图版本管理、巡检点位设置和路线规划。用户可从平台选择机器人并发起建图，查看建图状态，在现场走场完成后停止并保存地图；中心平台登记地图文件、预览、坐标原点、分辨率、来源机器人、质量状态和校验信息。技术人员可在指定地图版本上点击设置巡检点位，配置名称、位置、朝向和容差，并通过调整点位顺序形成可执行路线。软件对机器人当前地图、路线所属地图和任务地图进行一致性校验，防止将旧地图坐标用于新地图；路线保存后可供任务调度软件生成执行快照。太阳宫公园示范应用使用南入口、主步道、牡丹园和活动广场等业务点位组织日常巡检路线。

## ZC-04 无界公园机器人自主巡检任务调度软件V1.0

本软件由北京知川科技有限公司面向无界公园的周期性和临时性机器人巡检业务自主开发，用于管理巡检任务模板、执行计划、任务下发、执行状态和多点导航过程。管理员可将机器人、地图和路线组合成日常巡检、重点区域巡检或应急巡检任务，值守人员可选择预置任务立即执行；在调度功能通过正式版本验证后，也可按日历计划触发。每次执行创建独立实例并保存路线快照，避免路线后续修改影响历史记录。系统在下发前检查机器人连接、定位、地图版本和并发任务，执行过程中展示当前航点、总航点、完成比例、命令状态和失败原因，并支持暂停、继续和终止。中心平台与机器人边缘代理使用命令标识、确认结果和任务状态机保持双方一致，能够处理重复命令、网络中断和进程重启等异常情况。

## ZC-05 无界公园机器人远程指挥与应急处置软件V1.0

本软件由北京知川科技有限公司面向无界公园的远程值守及异常现场干预业务自主开发，为授权人员提供人工接管、运动控制、软急停、语音喊话和处置记录能力。用户在确认实时视频、网络状态和现场安全后进入接管模式，可下发前进、后退、横移、转向和停止等受控运动命令；系统在松开控制、切换设备或异常中断时优先执行停止策略。针对自行车禁行等开放空间管理事件，值守人员可结合告警位置和现场画面开展远程处置，并使用预置音频、文字转语音或网页录音向机器人扬声器下发劝导内容。软件记录命令创建、设备领取、执行结果和失败原因，使远程操作具备审计依据。运动控制消息与音频文件采用分离传输，兼顾控制实时性和媒体传输效率。返航功能仅在机器人端适配及现场验证完成后纳入正式版本说明。

## ZC-06 无界公园巡检轨迹与事件回溯管理软件V1.0

本软件由北京知川科技有限公司面向无界公园的机器人巡检过程留痕和安全事件复盘业务自主开发，用于采集、保存、查询和回放巡检轨迹，并将轨迹与机器人、任务、地图版本、控制命令、安全事件及媒体资料关联。机器人边缘端为轨迹点分配执行实例和连续序号，通过批量上报、离线缓存、恢复补传及应用层确认降低移动网络中断造成的数据缺失；中心平台对重复和乱序数据进行识别。值守人员可按机器人、任务和时间查询历史轨迹，在对应地图上查看行进路线、当前位置、目标点和告警位置，并通过时间线回溯任务启动、航点进度、暂停继续、异常发生和事件处置过程。软件在地图不匹配或定位丢失时保留原始状态而不绘制虚假轨迹，可按权限导出轨迹或巡检结果数据。完整自动巡检报告不属于V1.0默认功能。
