# 无界公园巡检轨迹与事件回溯管理软件V1.0使用说明书

著作权人：北京知川科技有限公司  
版本：V1.0  
文档状态：初稿

## 1. 软件概述

本软件面向无界公园巡检过程留痕和事件复盘需求，用于保存和回放机器人巡检过程，将任务执行、位置轨迹、控制命令、安全事件和媒体资料组织成可追溯记录。值守人员可以查询某次太阳宫公园巡检经过的区域、发生事件的位置以及后续处置结果。

## 2. 主要功能

1. 机器人位姿采集、序列编号和轨迹批量上报。
2. 断网缓存、恢复补传和重复批次控制。
3. 历史任务与轨迹列表查询。
4. 地图轨迹绘制、当前位置和目标点展示。
5. 轨迹与机器人、任务、地图版本关联。
6. 告警点、抓拍和处置记录关联。
7. 任务、命令、告警和媒体时间线查询。
8. 轨迹或巡检结果数据导出。

自动生成完整巡检报告不属于V1.0默认范围；完成开发后可作为升级版本功能或调整登记名称。

## 3. 操作说明

### 3.1 查询轨迹记录

进入轨迹回放页面，根据机器人、任务或时间选择记录。列表展示地图、采集时间、轨迹点数量和执行结果。

截图占位：`[ZC06-01 轨迹列表]`

### 3.2 回放巡检轨迹

选择记录后，系统加载对应地图版本和有序轨迹点，在地图上绘制巡检路线。无地图预览时保留坐标数据并提示无法绘图。

截图占位：`[ZC06-02 地图轨迹回放]`

### 3.3 查看任务时间线

执行详情按时间展示任务启动、航点进度、暂停、继续、结束、命令结果和异常原因。

截图占位：`[ZC06-03 任务时间线]`

### 3.4 回溯关联事件

在轨迹或时间线上查看告警位置、抓拍、视频引用和处置结果，形成“何时、何地、发现何事、如何处置”的记录。

截图占位：`[ZC06-04 轨迹与事件关联]`

### 3.5 导出数据

授权用户可导出轨迹或巡检结果。导出文件应包含数据时间范围、机器人和地图标识，并遵守项目数据保密要求。

截图占位：`[ZC06-05 数据导出]`

## 4. 异常处理

- 重复轨迹批次：按执行实例和序号幂等处理。
- 网络中断：机器人端暂存未确认数据，恢复后按序补传。
- 地图不匹配：不将轨迹绘制到错误地图。
- 定位丢失：保留状态事件，不伪造连续轨迹。
- 数据量过大：采用时间范围、分页和降采样控制展示负载。

## 5. 技术特点

软件为轨迹点设置执行实例、机器人、地图、采集时间和序号，能够区分重复、乱序和补传数据；事件与媒体通过统一标识关联，支持跨任务的历史查询和审计。
