# 无界公园机器人远程指挥与应急处置软件V1.0使用说明书

著作权人：北京知川科技有限公司  
版本：V1.0  
文档状态：初稿

## 1. 软件概述

本软件面向无界公园开放空间的远程值守需求，为值守人员提供机器人远程指挥、人工接管和现场语音干预能力。当平台发现异常事件或自主巡检需要人工协助时，授权人员可结合实时视频控制机器人停止、移动或前往指定区域，并通过预置语音、文字转语音或现场录音开展安全劝导。

## 2. 主要功能

1. 授权用户远程接管与释放接管。
2. 前进、后退、横移、转向和停止控制。
3. 软急停与控制状态提示。
4. 告警位置辅助定点处置。
5. 预置语音模板播放。
6. 文字转语音、网页录音、录音保存和播放。
7. 命令创建、领取、执行结果和超时记录。

返航仅在对应机器人端适配已经完成并通过现场验证后加入正式材料；自动回充不属于V1.0默认范围。

## 3. 操作说明

### 3.1 进入远程控制

选择机器人并确认实时视频、网络、设备状态和周边环境。点击接管，收到成功反馈后才可发送运动命令。

截图占位：`[ZC05-01 远程控制台]`  
截图占位：`[ZC05-02 接管成功]`

### 3.2 控制机器人运动

长按方向控制持续发送受限速度指令，松开时发送停止命令。切换机器人或退出页面前释放接管。

截图占位：`[ZC05-03 方向控制]`

### 3.3 使用语音喊话

用户可选择预置模板、输入文字生成语音，或在浏览器录音后保存并播放。机器人领取命令后下载音频并通过扬声器播放。

截图占位：`[ZC05-04 预置语音]`  
截图占位：`[ZC05-05 录音与文字喊话]`

### 3.4 处置安全事件

值守人员查看告警和现场视频，确认安全后接管或下发定点处置命令，并使用语音开展劝导。处置结束后退出接管并在事件中心填写结果。

截图占位：`[ZC05-06 异常现场处置]`

## 4. 安全限制

- 未进入接管状态时拒绝运动命令。
- 网络不稳定或视频不可见时不进行高风险远程移动。
- 松开方向按钮、切换设备或异常中断时优先发送停止。
- 急停后必须经现场安全确认才能恢复。
- 音频地址仅允许机器人能够安全访问的HTTP或HTTPS资源。

## 5. 技术特点

软件将浏览器操作转换为可审计的远程命令，记录命令创建、领取、执行和失败状态；运动控制与语音媒体分别处理，避免大文件进入实时控制消息通道。
