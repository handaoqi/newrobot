# 无界公园机器人地图构建与路线规划软件V1.0使用说明书

著作权人：北京知川科技有限公司  
版本：V1.0  
文档状态：初稿

## 1. 软件概述

本软件面向无界公园范围开放、通行路线动态的巡检场景，用于组织机器人现场建图、地图版本管理、巡检点位配置和路线规划。太阳宫公园示范流程为机器人沿目标区域完成走场建图，平台登记地图版本，技术人员在地图上配置南入口、主步道、牡丹园和活动广场等点位并形成巡检路线。

## 2. 主要功能

1. 建图开始、状态查询、停止保存和取消。
2. 地图文件同步、上传、下载和预览。
3. 地图元数据、质量状态和版本管理。
4. 活动地图选择及机器人端地图切换。
5. 地图点击取点、坐标和朝向配置。
6. 路线新建、点位排序、启停和路径预览。
7. 地图、机器人、点位和路线一致性校验。

## 3. 操作说明

### 3.1 发起现场建图

选择机器人，输入地图名称并启动建图。值守人员携带机器人走过目标区域，页面显示建图状态和进度。

截图占位：`[ZC03-01 建图启动]`

### 3.2 保存并同步地图

建图完成后停止并保存，机器人端生成地图文件，中心平台登记文件、分辨率、原点、校验值和预览图。失败时保留失败原因，不自动将异常地图设为活动地图。

截图占位：`[ZC03-02 地图保存与同步]`

### 3.3 查看和管理地图

地图页面展示名称、版本、来源机器人、预览、质量和启用状态。切换活动地图前确认机器人端已成功应用对应版本。

截图占位：`[ZC03-03 地图列表与预览]`

### 3.4 配置巡检路线

选择地图，在可通行区域依次添加点位，填写名称、朝向和容差，调整点位顺序后保存路线。

截图占位：`[ZC03-04 地图取点]`  
截图占位：`[ZC03-05 路线规划]`

## 4. 安全与异常处理

- 建图发散：标记地图质量，现场核对后再启用。
- 地图版本不一致：禁止直接执行绑定其他地图的路线。
- 点位不可达：调整到可通行区域并重新验证。
- 上传失败：保留机器人端地图文件，恢复网络后重新同步。
- 强制删除：删除前列出关联路线、任务、轨迹和告警，防止误删。

## 5. 技术特点

软件统一管理地图坐标、分辨率、原点和版本，将任务模板与当前地图的路线实例分离；任务执行时保存路线快照，避免后续编辑路线影响历史任务。
