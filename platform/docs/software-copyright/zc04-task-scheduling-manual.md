# 无界公园机器人自主巡检任务调度软件V1.0使用说明书

著作权人：北京知川科技有限公司  
版本：V1.0  
文档状态：初稿

## 1. 软件概述

本软件面向无界公园的周期巡检和临时巡检业务，负责组合机器人、地图和路线，创建任务模板并控制每次任务执行。软件支持任务下发、执行状态跟踪、多点导航、暂停、继续和终止，适用于日常巡检、重点区域巡检和应急巡检。

## 2. 主要功能

1. 巡检任务模板的新建、编辑、启停和删除。
2. 机器人、地图、路线及任务类型绑定。
3. 人工立即执行和日历计划配置。
4. 不可变路线快照和任务执行实例。
5. 多点巡检任务下发与命令确认。
6. 当前航点、完成比例和任务状态展示。
7. 暂停、继续、终止及失败原因记录。
8. 同一机器人并发运动任务控制。

## 3. 操作说明

### 3.1 创建任务模板

管理员输入任务名称，选择机器人、活动地图和巡检路线，保存任务模板。模板不直接写死其他地图的点位坐标。

截图占位：`[ZC04-01 创建巡检任务]`

### 3.2 配置巡检日历

在日历中选择日期、执行时间和任务模板。正式材料仅在调度器已经能够真实触发任务时描述“自动执行”；否则只展示计划管理能力。

截图占位：`[ZC04-02 巡检日历]`

### 3.3 启动任务

值守人员选择预置任务并点击开始。中心平台检查机器人在线状态、地图和任务冲突，创建执行实例并下发命令。

截图占位：`[ZC04-03 任务启动]`

### 3.4 查看执行进度

执行详情显示任务状态、当前航点、总航点、地图位置、轨迹和命令状态。页面刷新后仍可查询已保存的执行记录。

截图占位：`[ZC04-04 任务执行详情]`

### 3.5 暂停、继续和终止

暂停时机器人取消当前导航目标并确认停车；继续时根据未完成航点重新构建目标；终止后任务进入终态，不允许再次继续。

截图占位：`[ZC04-05 任务控制]`

## 4. 状态与异常处理

- 机器人离线、定位未就绪或地图不一致：拒绝启动并返回明确原因。
- 已有运动任务：拒绝第二个任务，避免冲突。
- 重复命令：使用命令标识幂等处理。
- 网络中断：按任务策略继续或停止；恢复后同步状态和结果。
- 服务重启：从持久化执行上下文恢复或将任务标记为中断。

## 5. 技术特点

软件使用任务模板、执行实例和远程命令三层模型，分别管理业务配置、一次实际执行和设备控制；通过状态机约束合法操作，并保存命令确认和最终结果。
