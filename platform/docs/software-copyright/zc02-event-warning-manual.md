# 无界公园安全事件智能识别与预警处置软件V1.0使用说明书

著作权人：北京知川科技有限公司  
版本：V1.0  
文档状态：初稿

## 1. 软件概述

本软件面向无界公园开放环境的安全管理需求，用于接收机器人端或中心智能识别服务产生的安全事件，结合位置、地图和区域规则形成可复核、可处置、可追溯的预警记录。太阳宫公园V1.0重点场景为“自行车进入公园禁行区域”，其他人员、车辆、垃圾和动物事件作为后续可扩展类型。

## 2. 主要功能

1. 智能识别事件接入与数据校验。
2. 事件抓拍、机器人、时间、位置和任务上下文关联。
3. 电子围栏和禁行区域管理。
4. 告警类型、等级、状态和重复事件控制。
5. 待处理、已处理事件筛选和关键词查询。
6. 事件详情查看、人工复核、备注和归档。
7. 告警数量、类型和趋势统计。

## 3. 业务流程

机器人采集现场图像后，识别服务输出目标类型和置信度；事件上报携带机器人、时间、位置、地图和媒体引用；中心平台保存事件并按规则生成告警；值守人员查看抓拍并提交复核结论；系统保存处理人、处理时间和备注。

## 4. 操作说明

### 4.1 配置禁行区域

管理员选择地图，创建区域名称并配置区域范围。区域必须绑定明确地图版本，防止地图切换后坐标误用。

截图占位：`[ZC02-01 电子围栏管理]`

### 4.2 查看事件列表

进入事件中心后，可按处理状态、时间和关键词筛选事件。列表展示事件标题、地点、机器人、发生时间和状态。

截图占位：`[ZC02-02 事件列表]`

### 4.3 查看事件详情

选择事件后查看抓拍、风险等级、位置、关联任务和识别信息。V1.0示例使用太阳宫公园自行车禁行事件。

截图占位：`[ZC02-03 自行车事件详情]`

### 4.4 复核与处置

值守人员填写处置备注并选择确认违规、误报或其他有效结论。提交后事件状态更新，操作记录用于后续回溯。

截图占位：`[ZC02-04 事件复核处置]`

### 4.5 查看统计

统计页面按日期和事件类型展示告警数量及变化趋势，为值守安排和规则调整提供参考。

截图占位：`[ZC02-05 告警统计]`

## 5. 异常处理

- 无抓拍：保留事件文本和媒体上传状态，允许稍后补传。
- 重复事件：按事件标识和去重键避免重复入库。
- 坐标缺失：事件仍可保存，但不得伪造具体位置。
- 误报：由授权人员提交复核结论并保留原始检测记录。

## 6. 技术特点

软件将模型检测结果与业务告警分离，检测记录必须经过区域规则或人工复核才能形成最终处置结论；事件、媒体、任务和位置使用统一标识关联，支持弱网环境下的延迟上传。
